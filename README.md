# Multiplexor

A terminal dashboard and CLI for local Minecraft servers and Pterodactyl fleets,
including builds, backups, content, Velocity networks, remote profiling, and
gameplay tools.

All documentation is maintained in the [Volmit docs](https://github.com/VolmitSoftware/docs/blob/master/servermultiplexor.md).
